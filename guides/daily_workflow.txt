Practical Daily Workflow (Beginner-Friendly)
1️⃣ Start cluster
docker start multi-control-plane multi-worker multi-worker2

2️⃣ Verify cluster is Ready
kubectl get nodes

3️⃣ Start Dashboard
kubectl proxy


Open browser:

http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/

4️⃣ Login
If the token works → paste it once
If token expired → regenerate:
kubectl -n kubernetes-dashboard create token admin-user




Important Notes
Deleting the cluster → lose everything → new token needed
Stopping Docker → cluster “paused” → token still valid after restart
Production → tokens are short-lived or controlled by RBAC / Azure AD / OIDC
