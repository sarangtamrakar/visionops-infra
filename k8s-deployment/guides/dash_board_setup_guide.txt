👉 Kubernetes Dashboard

Official project

Runs inside the cluster

🚀 STEP-BY-STEP: Install Kubernetes Dashboard
STEP 1️⃣ Deploy Dashboard
kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.7.0/aio/deploy/recommended.yaml


Wait:

kubectl get pods -n kubernetes-dashboard


All should be Running.

STEP 2️⃣ Create Admin User (Required)

Create file:

cat <<EOF > dashboard-admin.yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard
EOF


Apply:

kubectl apply -f dashboard-admin.yaml

STEP 3️⃣ Get Login Token
kubectl -n kubernetes-dashboard create token admin-user


👉 Copy the entire token (you’ll paste it in browser).

STEP 4️⃣ Access Dashboard (Port Forward)
kubectl proxy


Open browser:

http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/


Choose:

Token

Paste token

Login

🎉 You now have a full Kubernetes UI.

🧭 What You Can Do in Dashboard

See nodes

Debug crashes

Watch events

This helps you connect CLI → YAML → reality.
